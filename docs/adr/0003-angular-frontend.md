# 以學習 Angular 為目的遷移前端

本專案決定將監控與乘客介面由 Vanilla JavaScript 遷移至 Angular，目的是學習 Angular；目前沒有既有功能痛點，公司僅確認使用 Angular，版本與架構慣例尚不清楚，因此不以推測的公司做法作為依據。相較僅以 Angular 包裝既有 UI 接口，本次將畫面元件、HTTP 通訊與前端狀態管理納入遷移範圍，以增加實際使用 Angular 的學習內容，並接受較多的遷移與驗證工作。

既有功能與操作流程維持原樣，Python + FastAPI Server、Python 車輛 Client 與 HTTP 通訊分工維持不變，路線規劃與離線任務處理沿用既有 ADR。地圖與 3D SDK 保留專用封裝，由 Angular 銜接；遷移須保留既有的輪次核對、送單結果確認與避免重複送單行為。

本記錄確立遷移目的與範圍；建置方式、入口相容性與舊版介面保留策略仍待釐清，不代表已開始遷移實作。
