Simulation 共享狀態與 Lock

生命週期與使用方式

class Simulation:
    def __init__(self, ...):
        self.lock = asyncio.Lock()

    async def submit(self, data):
        async with self.lock:
            ...
  • 在 Simulation 建立一把鎖，讓這個物件的非同步方法共用它。
  • 進入 async with self.lock 前先取得鎖；鎖被占用時，coroutine 會等待。
  • 離開區塊時自動釋放，包括 return 或例外離開。
  • asyncio.Lock 協調 asyncio tasks，不用於 OS thread 同步。
