前端入口與模組追蹤

啟動路徑

npm run dev
  → Vite 提供根目錄 index.html
  → HTML 的 <script type="module" src="/src/main.js">
  → src/main.js 匯入 CSS 與畫面功能
  → mountMonitor() 或 mountPassenger()

讀程式的方式

  • HTML 的 src 指向哪個檔案？從那裡開始。
  • JavaScript 的 import 後面是相對路徑；沿著路徑打開檔案。
  • 遇到 mountX() 這種呼叫，使用搜尋找它的定義，再看它做了哪些初始化。

本專案定位

  • index.html：頁面骨架、DOM 元素與 JavaScript 入口。
  • src/main.js：前端分流入口。
  • src/monitor.js：監控畫面的初始化。
  • src/passenger.js：乘客畫面的初始化。
