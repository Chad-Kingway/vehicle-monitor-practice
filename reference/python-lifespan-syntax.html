lifespan 與字典展開

@asynccontextmanager

它是 Python contextlib 的 decorator，會把含有單次 yield 的 async generator 包成 async context manager。框架進入生命週期時，程式跑到 yield 前；框架完成服務、退出生命週期時，再執行 yield 後的清理。

@asynccontextmanager
async def lifespan(app):
    resource = await open_resource()
    try:
        yield  # 暫停，讓 app 開始工作
    finally:
        await resource.close()  # app 結束時清理

本專案以 FastAPI(lifespan=lifespan) 註冊它，在 yield 前建立 HTTP client、RoutePlanner 和 Simulation，結束時關閉資源。

官方說明：Python contextlib.asynccontextmanager、FastAPI Lifespan Events。

字典裡的 **mapping

在字典大括號內，** 會把 mapping 裡所有 key/value 加入新字典。項目由左到右加入；同一個 key 重複時，右邊最後出現的值會留下。

dotenv_values = {"MODE": "file", "PORT": "8000"}
os_environment = {"MODE": "system"}

settings = {
    **dotenv_values,
    **os_environment,
}
# 結果：{"MODE": "system", "PORT": "8000"}

因此本專案的 {**dotenv_values(...), **os.environ} 會先讀 `.env`，再合併系統環境變數；同名時系統環境變數覆蓋 `.env`。這裡的 ** 是字典展開；在 2 ** 3 這種位置則代表乘方。

官方說明：Python Dictionary displays。
