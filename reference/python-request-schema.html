乘車請求輸入模型

資料從哪裡進來

server/app.py 的 submit_request(data: RideRequestInput) 接受一個 HTTP request body。FastAPI 根據型別標註，使用 server/schemas.py 的模型解析與驗證 JSON。

RideRequestInput 規則

  • 必填：passenger_id、pickup、destination、passenger_count。
  • passenger_count：嚴格整數，且 >= 1。
  • pickup、destination：[經度, 緯度]；經度介於 -180 到 180，緯度介於 -90 到 90。
  • extra='forbid'：拒絕未宣告的額外欄位。

驗證成功後

FastAPI 才會呼叫 handler，並將已驗證的 RideRequestInput 物件交給 Simulation.submit(data)。
