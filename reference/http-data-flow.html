監控資料的 HTTP 路徑

一輪讀取

src/monitor.js
  startPolling(signal => api("/api/simulation", { signal }), render, ...)
      ↓
src/ui.js
  api(...) 使用 fetch(url) 發出 HTTP GET
      ↓
server/app.py
  @app.get('/api/simulation')
      ↓
server/simulation.py
  snapshot() 組合 run_id、settings、vehicles、requests、tasks
      ↓
回傳 JSON → 前端 render(data) 更新畫面

讀取失敗時

`startPolling()` 會顯示 Server 連線中斷；成功讀取才呼叫 `render(data)`，因此斷線時會保留最後顯示的資料。

相關檔案

  • src/monitor.js：安排讀取並把資料交給 render。
  • src/ui.js：呼叫 fetch 與安排輪詢。
  • server/app.py：定義 HTTP 路徑和方法。
  • server/simulation.py：產生回傳資料快照。
