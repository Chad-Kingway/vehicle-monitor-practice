Angular 在本專案的責任分層

啟動與建置

  • index.html 提供 <app-root> 掛載點。
  • src/main.ts 以 bootstrapApplication 啟動 WorkspaceComponent，並提供 HttpClient。
  • npm run dev 經 tools/angular.mjs 執行 Angular CLI；npm run build 產生 production browser bundle。

畫面與狀態

  • WorkspaceComponent：工作區外層、選擇監控／乘客畫面、持有地圖容器。
  • MonitorComponent、PassengerComponent：各自的畫面範本與使用者操作。
  • SimulationService：Signals、輪詢、操作及地圖生命週期。
  • ApiService：以 HttpClient 與 HTTP 連接 FastAPI。
  • vehicle-map.js：封裝勤崴 SDK 與 3D 車輛呈現。

追蹤時可以問

  1. 畫面從哪個掛載點開始？
  2. 哪個 component 顯示這個控制項？
  3. 點擊事件呼叫哪個 action？
  4. action 改變哪個 service state，或送出哪個 HTTP request？
  5. 哪個 component 範本讀取這個 state 並重繪？
