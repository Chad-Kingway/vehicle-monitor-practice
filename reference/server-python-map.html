Server Python 檔案地圖

先記分工

  • server/__main__.py：讀取啟動參數，建立 FastAPI app，啟動 Uvicorn Server。
  • server/app.py：建立 FastAPI app、載入啟動資源，將 HTTP 路徑連到處理函式。
  • server/schemas.py：定義請求資料和設定的欄位與驗證規則。
  • server/simulation.py：保存本輪模擬狀態，處理乘車請求、車輛回報與接送任務。
  • server/dispatch.py：依位置、載客上限與可用狀態挑選車輛。
  • server/routes.py：查詢並整理官方道路路線。

讀一個 API 的順序

  1. 在 app.py 找 HTTP decorator，例如 @app.get('/api/simulation')。
  2. 讀它下面的函式，看接收什麼、呼叫哪個服務物件。
  3. 沿著被呼叫的方法到 simulation.py，看資料怎麼回傳或改變。
  4. 若函式參數是某個 schema，再去 schemas.py 看資料欄位和限制。
