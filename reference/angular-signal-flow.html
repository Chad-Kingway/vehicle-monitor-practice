本專案的 Signal 更新流程

  1. poll() 取得 Server 快照。
  2. acceptSnapshot() 更新服務內部的 rawState。
  3. emit() 呼叫 current.set(getState())，更新 Writable Signal。
  4. 元件的 computed() 讀取唯讀 state() 並重算衍生值。
  5. 範本讀取計算 Signal，例如 {{ online() }}，Angular 更新對應畫面。

current 由 SimulationService 私有持有；元件透過 state 讀取最新值，不直接修改它。
