Angular track

@for (vehicle of fleet(); track vehicle.id) {
  <button>{{ vehicle.id }}</button>
}

track 指定資料項目的識別值，以對應清單更新前後的畫面列。順序由清單決定；既有列可沿用、移動，新項目建立，不再出現的項目移除。

  • track item.id：穩定資料身分；動態清單首選。
  • track $index：位置身分；適合固定清單。
  • track item：物件參考；HTTP 新物件可能造成重建。
  • key 在同一清單內應唯一、穩定，計算應簡單且無副作用。
  • 相同 ID 仍可更新文字、屬性及元件輸入。
  • track 不處理 API、排序或資料更新通知，也不快取已移除的列。
  • 同物件參考而追蹤屬性改變時，現代 @for 仍可能沿用畫面；不要用改 key 強制重建。
