非同步路由呼叫流程

本專案的乘車請求

async def submit_request(data: RideRequestInput):
    return await app.state.simulation.submit(data)
  1. FastAPI 驗證 JSON，建立 RideRequestInput。
  2. 路由將 model 物件傳進 Simulation.submit(data)。
  3. await 等待非同步方法完成，取得它的回傳值。
  4. 路由回傳該值，FastAPI 將它作為 HTTP response。

直接呼叫 async def 函式會得到 coroutine 物件；必須 await 才會執行並取得結果。
