# 02: 乘客終止後重選並查看新請求

**交付行為：** 乘客目前請求完成、取消或失敗後可重新選擇起訖並提出下一筆；新選點在輪詢期間保留，乘客地圖呈現新請求實際指派的承接車及目前接送階段道路路線。

**阻擋任務：** 無，可立即開始。

- [x] 進行中的請求仍限制重選及再次送出；完成、取消或失敗後可準備下一筆。
- [x] 使用者重選的上車點及下車點不被成功輪詢還原成上一筆起訖。
- [x] 新請求受理後，以該請求的 Server `vehicle_id` 顯示承接車及其最新回報位置，不沿用上一筆的車輛。
- [x] 前往接人時顯示 Server 規劃的接人道路路線，載客時切換為送人道路路線。
