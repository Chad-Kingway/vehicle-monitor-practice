# 03: 乘客頁跟隨承接車

**交付行為：** 乘客可在目前請求中開啟或關閉承接車跟隨；請求終止後自動停止跟隨。

**阻擋任務：** 無，可立即開始。

- [x] 開啟跟隨後，地圖持續以目前請求的承接車為鏡頭目標。
- [x] 乘客可手動關閉跟隨，關閉後輪詢不應重新啟動跟隨。
- [x] 請求完成、取消、失敗或切換到下一筆時清除舊的跟隨目標。
