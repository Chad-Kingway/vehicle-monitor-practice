# 01: 監控頁快速送出隨機請求

**交付行為：** 監控操作者按下「隨機送出一筆」後，另開一個新乘客頁；新頁在首次連線成功後自動提出一筆隨機請求並顯示進度。乘客頁原有的隨機送單功能維持不變。

**阻擋任務：** 無，可立即開始。

- [x] 每次操作使用新的乘客身分，並另開其乘客頁。
- [x] 新乘客頁首次成功讀取 Server 狀態後只提出一筆隨機請求。
- [x] 送出結果不明或重新整理時沿用既有請求識別及恢復流程，不重複建立請求。
- [x] 乘客頁既有的隨機送單按鈕仍可使用。

## Comments

- 2026-10-14：瀏覽器人工驗收完成；兩次監控入口開啟不同乘客身分，各自只建立一筆隨機請求。刷新乘客頁恢復單一目前請求；乘客頁原有隨機按鈕亦可建立請求。詳見 [整合驗收紀錄](../../../docs/manual-acceptance.md)。
