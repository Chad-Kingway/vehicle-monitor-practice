# 下一輪監控與乘客頁調整

本文件記錄需求訪談；功能尚未實作，待所有分支釐清並確認共同理解後發布完整規格。
上一輪基準為 [車輛監控規格](../vehicle-monitor/spec.md)。

## 已確認需求

### 監控控制與永久設定

- 監控頁速度控制改為滑動拉桿，範圍 1～300 倍、步進 1、預設 60 倍，保留執行中調速及不重置進度的要求；拖曳送出與保存細節待確認。
- 車輛回報與網頁更新維持兩個獨立的全域設定，預設各 0.25 秒。
- 監控頁提供兩種間隔的修改與永久保存入口，寫入既有 `config/simulation.json`；欄位操作、範圍與步進待確認。
- 儲存成功後立即更新 Server 設定，車輛與所有開啟的網頁於下一次成功通訊後採用，不重置模擬，重啟後保留。
- 保存失敗維持原設定；多個監控頁修改以最後成功保存的設定為準。
- 網頁更新設定套用所有現有網頁。程式查核顯示目前只有監控與乘客兩種網頁，車輛 Client 為 Python 程序；不因第一輪提及車輛頁而新增頁面。

### 乘客頁

- 移除乘客頁「新增乘客」入口，保留監控頁建立或開啟不同乘客身分的入口。
- 同一乘客身分最多一筆尚未結束的乘車請求，由 Server 保證限制。
- 同身分的不同分頁顯示同一筆請求，不能各自建立另一筆進行中請求；不同乘客可分別提出請求。
- 進度待確認仍占用單筆名額。
- 等待派車可以取消，不能修改起訖與人數，不能提出下一筆。
- 規劃路線、前往接人、載客行駛及進度待確認均不能取消、修改起訖與人數或提出下一筆。
- 完成、取消及失敗後可以準備並提出下一筆；失敗不自動建立另一筆。
- 取消與派車競爭時以 Server 結果為準。
- 送出結果不明時保存原次資料與識別碼，先恢復原次結果；需要重試時沿用同一識別碼，隨機請求沿用原起訖。刷新後繼續核對，確認前停用送出。
- 同身分跨頁送出競爭時，顯示 Server 已受理的那一筆。
- Server 新輪次清除舊輪次的目前請求及未確認送出，保留乘客身分與地圖偏好，提示「模擬已重新開始」，不自動重送舊請求。
- 顯示承接車輛位置，不新增司機資料模型。
- 進度採接送階段與該階段百分比；前往接人與載客行駛分段計算。
- 百分比沿用車輛 Client 回報，不另建整趟算法。等待派車、規劃路線只顯示階段，完成顯示已送達；失聯保留最後位置與百分比，標示「進度待確認」與最後回報時間，不推估後續進度。
- 乘客頁只專注一筆目前乘車請求。結束後保留最後一筆結果至提出下一筆，更早紀錄保留於 Server／監控頁，乘客頁不累積列表。
- 地圖只顯示承接車輛、目前請求的起訖標記與目前階段路線；接人時顯示接人路線，載客時改為送人路線。
- 首次取得路線調整鏡頭，其後保留手動操作，提供定位承接車按鈕；結束後停止追蹤車輛，保留起訖及最後路線至下一筆受理。

### 地圖顯示偏好

- 所有有地圖的頁面提供右上角 POI 按鈕，切換 `poi_` 圖層圖標與名稱。
- POI 預設顯示，偏好於同一瀏覽器保存，刷新後維持。
- 模型比例拉桿控制目前頁面顯示的所有車輛，行駛中可以調整，各頁面偏好在同一瀏覽器保存。
- 未保存偏好時，模型初始比例為 30；範圍、步進及拖曳套用仍待確認。
- POI 與模型比例按監控頁／乘客頁兩種頁面類型分別保存，不按乘客身分區分；同瀏覽器的所有乘客頁共用乘客頁偏好，同類型分頁同步修改，樣式重載後重套。這兩項偏好不寫入 Server 設定檔。

## 現況查核與原規格差異

- 既有速度預設 10，Server 接受大於 0 且不超過 300 的倍率；監控目前為數字輸入與套用按鈕，速度更新只保存在記憶體。
- 兩種間隔目前預設 1 秒，手動編輯設定檔並重啟 Server 生效，尚無網頁保存端點。本輪確認更換預設值、新增設定入口與執行中生效。
- 本輪以兩種間隔執行中保存並生效的決策，取代原規格「速度之外設定的執行中調整為範圍外」對這兩項的限制，其餘 Server 設定仍維持原規格。
- 乘客身分取自 URL 的 `passenger` 參數，刷新、複製網址或分頁沿用相同身分。
- 既有流程為 waiting、planning、pickup、transport、completed，另有 cancelled、failed。只有 waiting 可取消；進度待確認保留原任務與階段。
- Server 已依乘客與 `client_request_id` 去重，但瀏覽器未保存送出意圖，回應中斷後重送可能建立另一筆請求。
- 既有任務資料包含分段進度、路線與承接車輛最後回報位置；乘客頁尚未使用車輛與任務資料。
- 歷史目前保留於 Server 記憶體至重啟，不持久化；本輪尚未要求改變此生命週期。
- 舊專案 POI 有樣式重載重套與失敗還原，刷新不保存；模型比例為數字輸入、全車套用、行駛中禁止。新需求不能直接視為原樣移植。
- 舊專案只供唯讀參考。官方文件已確認 [onLayer](https://kw3dmap.localking.com.tw/3dmap/api/map/methods#onlayer)、[offLayer](https://kw3dmap.localking.com.tw/3dmap/api/map/methods#offlayer) 接受圖層名稱字串並依圖層 id 的「包含」比對，以及 [redraw](https://kw3dmap.localking.com.tw/3dmap/api/map/methods#redraw) 可強制同步重繪。
- 官方 [setScale](https://kw3dmap.localking.com.tw/3dmap/api/mapThree/model#setscale) 文件確認比例相對於模型建立時的 scale；未記載行駛中禁止調整，也未保證同時更新位置與比例的行為。實作仍須驗證行駛中及多模型調整，以及目標樣式的 `poi_` 是否涵蓋圖標與名稱。

## 待釐清分支

- 兩種間隔：Q9 的欄位操作、範圍與步進。
- 速度拉桿：拖曳送出、保存範圍、連線失敗。
- 模型比例：範圍與步進、套用時機與失敗。
- 恢復：初次載入及網頁讀取 Server 失敗時的操作。
- 偏好：SDK 套用失敗與瀏覽器無法保存時的處理。
- 實作驗證事項：SDK 行駛中／多模型比例調整與目標樣式 `poi_` 的實際顯示範圍。
- 訪談結束後確認共同理解，再決定完整規格與是否拆分實作任務。
