## 01：全車速度拉桿與續行

**交付行為：** 操作者在監控頁拖曳速度拉桿即可讓全車採用新倍率，接送從目前位置與進度續行。

**Blocked by：** 無，可立即開始。

**驗收條件：**

- [ ] 拉桿範圍 1～300、步進 1、預設 60，不另按套用。
- [ ] 拖曳最多每 0.25 秒送出一次，放開送出最終值，車輛於下一次成功通訊後採用。
- [ ] 車位、路線、任務及已完成路段不重置；只改速度，不改真實時間的回報或更新間隔。
- [ ] 更新失敗顯示簡短錯誤及 Server 已確認值。
- [ ] 本輪速度修改不永久保存，Server 重啟回設定檔預設值，本輪預設為 60。
- [ ] 人工操作真實接送中的拉桿，核對 Server 與 Client 的續行結果。

**覆蓋規格：** 使用者故事 1～6；人工驗收 1、2。

## 02：回報與網頁更新間隔永久設定

**交付行為：** 操作者在監控頁分別設定兩種間隔並永久保存，全車與各網頁在執行中採用，重啟後仍保留。

**Blocked by：** 無，可立即開始。

**驗收條件：**

- [ ] 兩種全域間隔獨立、預設各 0.25 秒；兩個可直接填秒數的數字欄位共用「儲存設定」按鈕。
- [ ] 範圍 0.1～60 秒、步進 0.05 秒，車輛回報間隔須嚴格小於目前離線門檻；不合法則說明原因並拒絕，不修改離線門檻。
- [ ] 成功同時代表永久保存及執行中更新；保存失敗維持原設定，只修改這兩項，保留設定檔其他內容。
- [ ] 各車輛、監控頁及乘客頁下一次成功通訊採用，不重置模擬，Server 重啟後保留。
- [ ] 多監控頁以最後成功保存為準，網頁輪詢不重疊，真實時間間隔不受速度倍率影響。
- [ ] 經 HTTP 與網頁核對合法修改、非法輸入、保存失敗、多頁修改及重啟保存。

**覆蓋規格：** 使用者故事 7～15；人工驗收 1、3、4。

## 03：每乘客單筆目前請求與操作界線

**交付行為：** 乘客手動或隨機送出後專注一筆目前乘車請求，同身分跨分頁也只能有一筆進行中請求；終止後可提出下一筆。

**Blocked by：** 無，可立即開始。

**驗收條件：**

- [ ] 移除乘客頁「新增乘客」，保留監控頁入口與網址乘客身分；不同乘客可各自送出。
- [ ] Server 保證同乘客跨頁／併發最多一筆進行中請求，手動與隨機共用限制；進度待確認也占用名額。
- [ ] 同身分跨頁競爭收斂至 Server 已受理的請求，保留既有識別碼去重契約。
- [ ] 等待派車可取消；所有進行中狀態不得修改起訖／人數或提出下一筆，規劃開始及進度待確認不接受取消。
- [ ] 取消與派車競爭以 Server 結果為準；完成、取消、失敗後才可再送，失敗不自動建立另一筆。
- [ ] 目前請求優先為進行中，否則為最近終止結果；終止結果留至下一筆受理，乘客頁不累積列表，本輪較早紀錄仍在 Server／監控頁。
- [ ] 經 HTTP 併發與實際同身分雙分頁核對單筆限制及各狀態操作。

**覆蓋規格：** 使用者故事 16～29；人工驗收 1、5、6。

## 04：請求送出結果不明與刷新恢復

**交付行為：** 乘客在回應遺失、刷新或連線中斷後恢復原次請求，不建立重複請求；Server 新輪次則讓乘客自行提出新需求。

**Blocked by：** 03：每乘客單筆目前請求與操作界線。

**驗收條件：**

- [ ] 保存原次送出資料與識別碼，結果不明先核對，必要重試沿用同一識別碼；隨機請求沿用原次起訖。
- [ ] 刷新後繼續核對原次操作，結果未確認前禁止新的送出；同身分不同分頁仍收斂至同一筆受理結果。
- [ ] 首次載入及讀取 Server 失敗時停用送出／取消，重新成功讀取後恢復適當操作；已有畫面保留並標示連線中斷。
- [ ] 網頁斷線與 Server 判定車輛失聯分別呈現，不因網頁讀取失敗推斷車輛離線。
- [ ] 新輪次清除舊目前請求與未確認送出，保留乘客身分及地圖偏好，提示「模擬已重新開始」，不自動重送。
- [ ] 模擬已受理但回應遺失後刷新、隨機重試及 Server 重啟，從 HTTP 與網頁核對無重複請求。

**覆蓋規格：** 使用者故事 30～35；人工驗收 5、8、9。

## 05：乘客承接車位置與分段接送進度

**交付行為：** 乘客在目前請求的地圖與狀態區掌握承接車位置、當前階段路線與分段百分比，失聯及結束時保留正確資訊。

**Blocked by：** 03：每乘客單筆目前請求與操作界線。

**驗收條件：**

- [ ] 使用 Server 既有請求、任務及車輛關聯，只顯示承接車、目前起訖及當前階段路線，不新增司機模型。
- [ ] 接人顯示接人路線，載客改為送人路線；沿用車輛回報的當前段百分比並明示階段，不另算整趟。
- [ ] 等待與規劃只顯示階段，完成顯示已送達；車輛失聯保留最後位置及百分比，顯示進度待確認與最後回報時間，不推估。
- [ ] 首次取得路線調整鏡頭，後續輪詢保留手動操作，提供定位承接車按鈕。
- [ ] 結束後停止追蹤承接車，保留最後結果、起訖及路線至下一筆受理，下一筆切換後不混入舊資料。
- [ ] 實際瀏覽器觀察接人、載客、失聯恢復及終止，核對路線、進度與鏡頭。

**覆蓋規格：** 使用者故事 36～42；人工驗收 7、8。

## 06：POI 切換與顯示偏好恢復

**交付行為：** 使用者在各地圖右上角切換 POI 圖標與名稱，並在刷新、同類分頁及樣式重載後維持選擇。

**Blocked by：** 無，可立即開始。

**驗收條件：**

- [ ] 監控與乘客地圖提供右上角 POI 按鈕、初始顯示，切換目標圖層的圖標與名稱，實際查核目標樣式範圍。
- [ ] 同瀏覽器按監控／乘客頁面類型分別保存，不按乘客身分區分；所有乘客頁共用偏好，同類分頁同步。
- [ ] 刷新與樣式重載重套偏好；只在套用成功後保存，不寫入 Server 設定。
- [ ] 套用失敗嘗試還原並提示簡短錯誤；還原失敗暫停該控制，待地圖重載恢復。
- [ ] 僅瀏覽器保存失敗時本頁繼續使用已套用選擇，提示「偏好未保存」。
- [ ] 依官方 SDK 方法與舊專案唯讀參考，實際網頁驗證切換、跨頁／刷新／樣式重載及失敗處理。

**覆蓋規格：** 使用者故事 43、44、48～52 的 POI 行為；人工驗收 1、10～12 的 POI 行為。

## 07：行駛中模型比例拉桿與偏好

**交付行為：** 使用者拖曳本頁全車比例拉桿，行駛中立即縮放且不影響位置更新；刷新保留偏好，後續模型繼承目前比例。

**Blocked by：** 無，可立即開始。

**驗收條件：**

- [ ] 範圍 1～100、步進 1，未保存偏好時初始 30，拖曳立即套用，本頁所有模型使用相同比例，行駛中可調。
- [ ] SDK 比例依官方建立基準計算，不累乘；實際多模型位置／朝向更新與縮放各自正確。
- [ ] 空車隊可先設定比例，後續模型載入繼承目前比例，適用共用地圖的監控及乘客頁。
- [ ] 偏好按監控／乘客頁面類型分別保存，同類分頁同步、乘客身分共用，刷新與樣式重載後重套，不寫入 Server 設定。
- [ ] 僅套用成功才保存；失敗嘗試還原並提示，還原失敗暫停控制至地圖重載；保存失敗則本頁使用已套用值並提示「偏好未保存」。
- [ ] 實際監控多車行駛中拖曳並核對位置與比例持續正確；乘客承接車顯示與比例組合於 08 一併驗收。

**覆蓋規格：** 使用者故事 45～52 的比例行為；人工驗收 1、10～12 的比例行為。

## 08：本輪 HTTP 與網頁整合驗收

**交付行為：** 操作者可依實際執行紀錄核對整輪功能、組合行為與剩餘驗收缺口。

**Blocked by：** 01～07 的全部功能任務。

**驗收條件：**

- [ ] 執行規格全部 12 項人工情境，逐項記錄操作、可觀察結果及未通過／未執行的原因。
- [ ] 核對 0.25 秒更新下調速、單筆限制、跨頁送出、回應遺失及新輪次恢復的組合行為。
- [ ] 在實際乘客承接車地圖核對 POI、比例、鏡頭、階段路線，以及偏好同步／重載與車位更新的組合行為。
- [ ] 同輪失聯只阻斷 HTTP、保留程序；核對進度待確認仍占用名額，恢復原任務，不轉派或提前完成。
- [ ] 執行適用的現有建置、語法、依賴及差異檢查；不得以檢查成功宣稱網頁／SDK 項目通過。
- [ ] 不新增測試檔；遇到必須新增且有具體回歸風險時依專案規範先取得同意。
- [ ] 驗收記錄明確區分已實測、失敗與未執行；缺口未解決不標記任務完成，不擅自修改父規格。

**覆蓋規格：** 全部使用者故事及 12 項人工驗收，重點為跨功能整合。

## 相依理由與執行方式

- 04 依賴 03 的單筆受理與目前請求呈現，才能可靠恢復或收斂原次請求。
- 05 依賴 03 的目前請求選擇與生命週期，才能確保地圖只追蹤正確的一筆。
- 04 與 05 互不阻擋，03 完成後可分別進行；它們的組合於 08 核對。
- 06 與 07 皆可在現有共用地圖獨立展示，無需等待 05。共用程式的修改須協調，但共用同一模組不是阻擋邊。
- 08 等待所有功能任務完成，避免以未完成的功能執行整輪驗收。
- 沒有需要獨立前置任務的跨層重構；必要的小幅整理併入對應功能，維持既有呼叫方式可用。共用偏好及地圖生命週期能力優先沿用已完成的實作，避免重複。
- 每張任務已分別發布，Status 為 ready-for-agent；有阻擋項的任務仍須等阻擋完成。可立即開始的 frontier 為 01、02、03、06、07。
