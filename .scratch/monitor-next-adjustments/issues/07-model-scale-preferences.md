# 07：行駛中模型比例拉桿與偏好

**來源規格：** [下一輪監控與乘客頁調整規格](../spec.md)

**交付行為（What to build）：** 使用者拖曳本頁全車比例拉桿，行駛中立即縮放且不影響位置更新；刷新保留偏好，後續模型繼承目前比例。

**Blocked by:** 無，可立即開始。

**驗收條件：**

- [ ] 範圍 1～100、步進 1，未保存偏好時初始 30，拖曳立即套用，本頁所有模型使用相同比例，行駛中可調。
- [ ] SDK 比例依官方建立基準計算，不累乘；實際多模型位置／朝向更新與縮放各自正確。
- [ ] 空車隊可先設定比例，後續模型載入繼承目前比例，適用共用地圖的監控及乘客頁。
- [ ] 偏好按監控／乘客頁面類型分別保存，同類分頁同步、乘客身分共用，刷新與樣式重載後重套，不寫入 Server 設定。
- [ ] 僅套用成功才保存；失敗嘗試還原並提示，還原失敗暫停控制至地圖重載；保存失敗則本頁使用已套用值並提示「偏好未保存」。
- [ ] 實際監控多車行駛中拖曳並核對位置與比例持續正確；乘客承接車顯示與比例組合於 08 一併驗收。

**覆蓋規格：** 使用者故事 45～52 的比例行為；人工驗收 1、10～12 的比例行為。
