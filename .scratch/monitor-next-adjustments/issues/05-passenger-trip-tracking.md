# 05：乘客承接車位置與分段接送進度

**來源規格：** [下一輪監控與乘客頁調整規格](../spec.md)

**交付行為（What to build）：** 乘客在目前請求的地圖與狀態區掌握承接車位置、當前階段路線與分段百分比，失聯及結束時保留正確資訊。

**Blocked by:** [03：每乘客單筆目前請求與操作界線](03-single-current-ride-request.md)

**驗收條件：**

- [ ] 使用 Server 既有請求、任務及車輛關聯，只顯示承接車、目前起訖及當前階段路線，不新增司機模型。
- [ ] 接人顯示接人路線，載客改為送人路線；沿用車輛回報的當前段百分比並明示階段，不另算整趟。
- [ ] 等待與規劃只顯示階段，完成顯示已送達；車輛失聯保留最後位置及百分比，顯示進度待確認與最後回報時間，不推估。
- [ ] 首次取得路線調整鏡頭，後續輪詢保留手動操作，提供定位承接車按鈕。
- [ ] 結束後停止追蹤承接車，保留最後結果、起訖及路線至下一筆受理，下一筆切換後不混入舊資料。
- [ ] 實際瀏覽器觀察接人、載客、失聯恢復及終止，核對路線、進度與鏡頭。

**覆蓋規格：** 使用者故事 36～42；人工驗收 7、8。
