# 12：網頁與生成器的斷線恢復

Status: done
Blocked by: 05：多乘客身分與等待請求取消；07：限量自動生成乘車請求

## 交付行為

網頁連線中斷時保留最後資料與中斷標示，生成器暫停送單，恢復後繼續剩餘筆數而不補發。

## 驗收條件

- [x] 監控與乘客網頁斷線保持最後資料，不誤認為資料仍即時更新。
- [x] 恢復後繼續讀取 Server 狀態並保留乘客原身分。
- [x] 生成器暫停，恢復不集中補發且維持剩餘筆數，間隔仍使用真實時間。
- [x] 以 HTTP 中斷驗證，不重啟 Server。

## 人工驗收方式

保持同輪程序執行，阻斷網頁與生成器 HTTP；確認網頁保留資料並標示中斷、生成器暫停。恢復後確認乘客身分保持、資料更新、生成器繼續剩餘量而沒有集中補發。
