# 10：路線失敗、重試與併發限制

Status: done
Blocked by: 04：三車容量與等待順序派遣

## 交付行為

無可行路線與重試耗盡時，乘客及監控看到失敗原因，車輛釋放；多筆任務查詢有明確併發上限。

## 驗收條件

- [x] 接人或送人任一段無路線時請求與任務失敗、保留原因並釋放原車。
- [x] 暫時錯誤每次最多等待 10 秒、最多三次；設定可調且重啟生效。
- [x] 非同步查詢遵守已查核的可設定併發限制，不阻塞其他 Client 資料互動。
- [x] 用可控制的查詢結果重現錯誤並做人工驗收，不新增測試檔。

## 人工驗收方式

用可控制的路線查詢情境分別重現無路線、逾時與暫時性錯誤，核對等待／嘗試上限、失敗原因及車輛釋放；多筆請求同時規劃時觀察併發上限與其他 Client 的資料互動。
