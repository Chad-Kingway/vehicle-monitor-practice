# 08：車隊與任務監控及鏡頭跟隨

Status: ready-for-agent
Blocked by: 04：三車容量與等待順序派遣

## 交付行為

監控顯示所有車輛及車隊、請求、任務列表；選車顯示路線與起訖，可定位與跟隨。

## 驗收條件

- [ ] 三種列表由 Server 資料更新，車輛選取與任務關係正確。
- [ ] 選車顯示其道路路線及起訖點，定位與跟隨目標切換正確。
- [ ] 多車模型位置與朝向互不影響，前端不接管模擬或派車。
- [ ] 頁面文字精簡，避免重複解釋可見狀態。

## 人工驗收方式

讓三台車同時處理請求，逐台選取、定位與跟隨，核對列表、任務路線與起訖；切換選車後確認鏡頭與路線沒有跟錯車。
