# 04：三車容量與等待順序派遣

Status: ready-for-agent
Blocked by: 03：單筆乘車請求完成接送

## 交付行為

以預設三台四人座車輛執行請求；選最近合適空閒車、全忙時等待、依容量略過暫時不可服務請求並保留順位。

## 驗收條件

- [ ] 車數、各車容量與不同固定初始位置可設定。
- [ ] 各車的位置、朝向、模型與任務進度獨立；同模型 URL 不造成車輛互相影響。
- [ ] 按送出順序掃描，選符合容量且空閒車的最近直線距離；選車邏輯集中在可替換派車模組。
- [ ] 超過車隊最大容量拒絕；合適車忙碌則等待；可略過但不重置原順位。
- [ ] 每車同時只執行一任務，不共乘或預約忙碌車。

## 人工驗收方式

以三台車與不同容量設定送出多筆請求，核對直線距離選車、忙碌等待、容量拒絕與略過保留順位；確認同時行駛的車輛模型與進度互不影響。
