# 09：全域設定與即時速度控制

Status: ready-for-agent
Blocked by: 04：三車容量與等待順序派遣

## 交付行為

監控即時調整全車速度且不重置位置或進度；依設定表重啟生效的設定可修改並取得一致結果。

## 驗收條件

- [ ] Server 統一提供全域設定，車輛經 HTTP 取得速度更新，不重置路段、任務或位置。
- [ ] 行駛預設 10 倍；回報與網頁更新分別預設 1 真實秒，不受速度倍率影響。
- [ ] 車數、各車容量／初始位置、回報／更新間隔、離線門檻、路線等待／嘗試／併發與隨機設定依規格重啟模擬生效。
- [ ] 生成間隔／總數只重啟生成器生效；路線併發初始值依整合查核決定。
- [ ] 驗收啟動設定變更的可見結果並提供操作說明。

## 人工驗收方式

在車輛行駛中多次調整速度，核對所有車採用更新且位置／進度未重置；觀察回報與網頁更新仍按真實時間。依設定表更改數量、容量、初始位置或頻率並重啟驗證。
