# 06：一鍵隨機提出乘車請求

Status: awaiting-validation
Blocked by: 04：三車容量與等待順序派遣

## 交付行為

乘客一鍵生成並送出一筆隨機請求，Server 依既定規則自動派車，範圍、人數與抽樣限制一致。

## 驗收條件

- [x] 範圍預設經度 121.5102～121.5693、緯度 25.03068～25.06026。
- [x] 人數取 1 至車隊最大載客上限；起訖直線距離至少 200 公尺、抽樣最多 20 次。
- [x] 範圍、最短距離與抽樣上限可設定；失敗顯示原因而不送單。
- [x] 生成規則提供自動生成程式重用，不讓兩者各自定義不同規則。

## 人工驗收方式

多次按單筆隨機送單，核對每次只有一筆、地理範圍、人數及最短距離；使用難以符合距離的範圍驗證抽樣上限與失敗不送單，再還原設定。
