# 02：官方道路路線取得與顯示

Status: done
Blocked by: 01：本機車輛連線與監控地圖

## 交付行為

以起訖點經 Server 取得官方道路路線，前端顯示相同路線與起訖標記，驗證座標、距離與時間可用。

## 驗收條件

- [x] 查核官方 REST 權限、憑證與服務限制，不將前端 SDK 方法當成 Python 介面。
- [x] Server 以非同步 HTTP 取得路線，核對實際回應與 encoded polyline 解碼。
- [x] 前端顯示 Server 路線與不同起訖標記；此顯示用於整合驗收，不新增已確認規格外的產品功能。
- [x] 無有效權限或憑證時明示限制，不以假路線宣稱真實整合成功。

服務權限與憑證仍須實際查核。無有效憑證、權限或可用服務時，記錄明確阻礙，不猜 API，不用假路線宣稱本張驗收完成。

## 人工驗收方式

選取一組已確認可行的起訖點，經 Server 取得勤崴道路路線；核對地圖線形、起訖標記、座標順序、距離與時間。記錄服務權限查核結果，勿將憑證寫入文件或 commit。

## 規格依據

規格使用者故事：25。依已確認的第一版規格；本張只交付上述切片，後續功能依各自任務逐步完成。

## 實作約束

依已確認規格與既有 ADR 實作，僅修改本專案，舊專案限唯讀參考；模型保持 Git 忽略。文件、註解與 commit 使用繁體中文；完成改動後建立 Git commit 並說明人工驗收。預設不新增測試或測試檔，保留並執行既有有效檢查；若需新增測試檔，先取得使用者同意。
