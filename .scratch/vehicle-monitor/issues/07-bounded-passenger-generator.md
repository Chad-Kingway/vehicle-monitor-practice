# 07：限量自動生成乘車請求

Status: ready-for-agent
Blocked by: 06：一鍵隨機提出乘車請求

## 交付行為

獨立 Python 乘客模擬程式可啟停，預設每 5～15 真實秒隨機送一筆、最多 20 筆後停止。

## 驗收條件

- [ ] 每筆代表新模擬乘客，透過 HTTP 提交並可在監控看到。
- [ ] 使用與單筆隨機相同的範圍、人數、距離與抽樣限制，失敗不送單。
- [ ] 生成間隔、總數可設定；重新啟動該程式不清空 Server 資料。
- [ ] 乘客網頁沒有持續生成開關，操作者由獨立程式控制。

## 人工驗收方式

啟動生成器，觀察真實時間間隔與新乘客身分，確認預設達 20 筆停止；修改間隔／總數後只重啟生成器，確認 Server 原有請求仍存在。另驗證操作者停止及生成失敗不送單。

規格使用者故事：29、30、31、32。依已確認的第一版規格；本張只交付上述切片，後續功能依各自任務逐步完成。
