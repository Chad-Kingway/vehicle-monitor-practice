# 05：多乘客身分與等待請求取消

Status: ready-for-agent
Blocked by: 03：單筆乘車請求完成接送

## 交付行為

新增乘客入口開出不同身分的頁面，刷新保留身分，各自看自己的請求；等待時可取消並保留紀錄。

## 驗收條件

- [ ] 免登入、多頁不同乘客，重新整理保持該頁原身分。
- [ ] 每位乘客可查看自己的請求並取消等待中的請求。
- [ ] 規劃開始後拒絕取消；取消與派車交錯時不出現已取消仍接送。
- [ ] 人工驗收以單車忙碌造成等待即可，不依賴完整三車功能。

## 人工驗收方式

開啟多個新增乘客頁面，各自送單並重新整理，核對身分與請求歸屬；在車輛忙碌時取消等待請求，再重現取消與開始規劃交錯，確認沒有已取消仍接送。
