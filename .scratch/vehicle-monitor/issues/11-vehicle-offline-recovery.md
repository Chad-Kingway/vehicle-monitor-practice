# 11：車輛斷線與原任務恢復

Status: ready-for-agent
Blocked by: 04：三車容量與等待順序派遣

## 交付行為

載客車斷線完成送達，未載客暫停；Server 保留原任務待確認，恢復後核對進度或完成結果且不重複處理。

## 驗收條件

- [ ] 超過 10 真實秒未回報標示離線、排除派車，原任務不立即失敗或轉派。
- [ ] Client 已有載客則沿快取路線送達等待；未載客停止行駛接人；空閒不接單。
- [ ] Client 保存同輪暫時斷線進度／送達結果，恢復後依原任務核對，不回退位置。
- [ ] 未載客先確認任務有效；已送達先確認完成才能接新單。
- [ ] 同一完成結果只處理一次，上一筆重複完成不清除新任務或錯誤釋放車。
- [ ] 永久失聯或 Client 結束保持待確認，由操作者重啟模擬。
- [ ] 人工只阻斷 HTTP 保持程序存活，驗證其他車仍接新請求且原請求不重派。

## 人工驗收方式

保持程序執行，只阻斷指定車輛 HTTP：載客前應暫停、載客後應送達等待；超過門檻 Server 保留任務待確認且其他車可接新單。恢復後核對不回退與送達完成，再重送上一筆完成確認不破壞新任務。
