Vehicle Monitor · Lesson 14

Signal 如何讓車隊數字更新？

沿著一次監控資料更新，看 Angular 怎麼知道要重算並重畫。

Signal 是會通知讀取者的值

一般變數的值改了，Angular 不一定知道哪個畫面依賴它。Signal 是 Angular 可追蹤的值：讀取時呼叫它，Angular 記下誰讀了；Signal 更新時，讀取它的計算與範本就能更新。Signal 的讀取方式是函式呼叫，例如 state()。

本專案用可寫 Signal 對外提供唯讀狀態

SimulationService 有兩個相關欄位：

private readonly current: WritableSignal<UiState>;
readonly state: Signal<UiState>;

this.current = signal(this.getState());
this.state = this.current.asReadonly();

current 由服務內部更新；元件拿到的 state 只能讀，不能直接改。這讓服務保有狀態寫入權，畫面則訂閱最新狀態。

從 Server 快照到畫面上的「在線」數字

輪詢收到新的 Server 快照後，服務的 acceptSnapshot() 更新內部 rawState，再呼叫 emit()。emit() 會執行 current.set(this.getState())，把新狀態放進 Signal。

MonitorComponent 用 computed() 從 Signal 計算在線車輛數：

readonly online = computed(() =>
  this.client.state().snapshot?.vehicles
    .filter(vehicle => vehicle.connection_status === 'online').length || 0
);

範本用 {{ online() }} 顯示這個計算值。因為範本讀取了 Signal，Angular 會追蹤這個相依關係。收到新快照 → current.set(...) → online() 重算 → 頁面上的在線數字更新。

讀程式時找這三步：誰寫 Signal？誰讀 Signal？讀到的值在哪個範本顯示？

小練習

Server 回來的新快照已放進 rawState，但在線數字要更新，服務還會呼叫哪個方法？在 simulation.service.ts 的 emit() 裡，找出那一行。
