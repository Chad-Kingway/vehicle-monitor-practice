Vehicle Monitor · Lesson 05

讀懂第一個 Server 路由

用最短的 GET API 認識 app.py 裡的 Python。

先知道每個 Python 檔案在負責什麼

Server 不是一支 Python 檔包辦所有事情：

  • __main__.py：啟動程式。
  • app.py：HTTP 路徑與請求的入口。
  • schemas.py：資料長相與輸入驗證。
  • simulation.py：模擬狀態與主要處理邏輯。
  • dispatch.py：挑選可接任務的車輛。
  • routes.py：取得及整理道路路線。

完整清單在Server Python 檔案地圖。這堂課只讀 app.py 的資料讀取路由。

逐行拆解

在 server/app.py 找到這段：

@app.get('/api/simulation')
async def get_simulation():
    return app.state.simulation.snapshot()
  1. @app.get('/api/simulation')：上面的裝飾器告訴 FastAPI，收到 GET /api/simulation 時，交給下面的函式處理。
  2. async def get_simulation():：定義一個名為 get_simulation 的函式。先把 async 當成這個 API 使用的函式形式；之後再單獨學非同步細節。
  3. 縮排的下一行是函式內容。Python 用縮排標出哪些程式屬於這個函式。
  4. return ...：把結果交回 FastAPI，讓它回傳給發出請求的網頁。

最右邊的 snapshot() 是向模擬物件索取一份目前狀態；它在 server/simulation.py 定義，會整理出輪次、設定、車輛、請求與任務資料。

先用箭頭讀：網址和方法 → 函式名稱 → 函式呼叫 → return 回應。逐字都不懂也沒關係，先認出這四個位置。

小練習

若監控網頁發出 GET /api/simulation，FastAPI 會呼叫哪個函式？請從程式片段找出函式名稱。

回覆函式名稱就可以；下一步再一起讀懂 app.state.simulation.snapshot() 裡的點號與括號。
