Vehicle Monitor · Lesson 04

網頁怎麼拿到車輛資料？

沿著一個網址，從瀏覽器追到 FastAPI。

前端定時讀取

在 src/monitor.js 最後，監控畫面啟動輪詢：

startPolling(
  signal => api("/api/simulation", { signal }),
  render,
  byId("connection")
);

這代表程式反覆呼叫 api("/api/simulation")，成功時把收到的資料交給 render。`api()` 在 src/ui.js 裡用瀏覽器的 fetch(url) 發出 HTTP 請求；沒指定其他方法時，預設是 GET，也就是讀取資料。

Server 用相同路徑接住請求

打開 server/app.py，找到：

@app.get('/api/simulation')
async def get_simulation():
    return app.state.simulation.snapshot()

@app.get(...) 把 HTTP GET 和網址路徑配對到 Python 函式。這裡呼叫 snapshot()，取得車輛、乘車請求、任務和設定等資料，FastAPI 再把它回傳給網頁。

整條線可以濃縮成：monitor.js → ui.js 的 fetch → app.py 路由 → simulation.py snapshot → render(data)。

追 API 的方法：先在前端搜尋網址字串（例如 /api/simulation），再在 Server 搜尋同一字串；通常就能找到請求的兩端。

找出 Server 端的入口

這個網頁用 GET 讀取資料。`server/app.py` 裡，哪一行把 /api/simulation 路徑交給 get_simulation()？請回覆 decorator 那一行。
