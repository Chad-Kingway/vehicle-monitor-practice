Vehicle Monitor · Lesson 08

Server 啟動與關閉時做什麼？

讀懂 lifespan：共享資源何時建立、何時清理。

lifespan 包住整個服務期間

server/app.py 定義 lifespan，並傳給 FastAPI(..., lifespan=lifespan)。FastAPI 會在開始收請求前進入它；服務結束時，再執行清理部分。

看 yield 前後的順序

先記住三段：yield 前 = 啟動準備；停在 yield = 正常接收請求；離開 yield 後 = 關閉清理。
  1. 啟動準備：讀設定，建立 HTTP client、RoutePlanner 和 Simulation，並將共用物件放到 app.state。
  2. 接收請求：執行到 yield 後，FastAPI 開始服務；API handler 可以讀取 app.state.simulation。
  3. 關閉清理：Server 停止服務後，程式從 yield 後繼續，呼叫 await simulation.close()；離開 async with 時，HTTP client 也會關閉。
@asynccontextmanager
async def lifespan(app: FastAPI):
    # 啟動：建立共享資源
    async with httpx.AsyncClient(...) as client:
        simulation = Simulation(settings, planner)
        app.state.simulation = simulation
        try:
            yield  # FastAPI 在這段期間接收請求
        finally:
            await simulation.close()  # 關閉時清理

實際程式還會讀設定和建立 RoutePlanner。這個生命週期讓每個 request 重用同一個 Simulation 和 HTTP client，避免每次請求都重新建立。

小練習

app.state.simulation = simulation 發生在 yield 前。為什麼這很重要？

提示：FastAPI 要先完成啟動準備，才會開始呼叫 API handler。
