Vehicle Monitor · Lesson 06

讀懂 Server 的物件與方法

拆開 app.state.simulation.snapshot()，追資料從哪裡來。

物件放在哪裡？

在 server/app.py 的啟動流程裡，程式會建立模擬器，再把它放進 FastAPI 的 app.state：

simulation = Simulation(settings, planner)
app.state.simulation = simulation

把 . 想成「從左邊這個東西，取得右邊的欄位或功能」。所以 app.state.simulation 表示：從 app 找到 state，再從 state 找到 simulation 物件。

最後的括號代表呼叫

繼續看 server/simulation.py，模擬器類別裡有：

def snapshot(self):
    return {
        'run_id': self.run_id,
        'settings': self.settings,
        'vehicles': [...],
        'requests': [...],
        'tasks': [...],
    }

snapshot 是這個模擬器提供的方法；加上 () 就是執行它。self 指正在執行這個方法的 Simulation 物件，所以 self.vehicles 是這一輪模擬器裡保存的車輛。

大括號 {...} 在這裡建立一份字典，裡面用名稱對應資料。return 把字典交回 get_simulation()，FastAPI 再轉成 JSON 回給網頁。

讀法：app.state.simulation.snapshot() = 找到模擬器 → 執行它的 snapshot 方法 → 取得一份目前狀態。
