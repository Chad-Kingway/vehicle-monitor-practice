Vehicle Monitor · Lesson 02

程式怎麼找到畫面上的欄位？

把 HTML 的一個 id，連到 JavaScript 的一次更新。

HTML 先留好位置

監控頁的 HTML 已經有車輛朝向欄位。打開 index.html 找這行：

<dd id="heading">—</dd>

id="heading" 是這個元素的名字。頁面剛載入時先顯示破折號，等資料來了再更新。

JavaScript 透過 id 找到它

在 src/monitor.js，監控畫面建立一個方便重複查找的函式：

const byId = (id) => document.getElementById(id);

之後的 renderSelection() 取得目前車輛資料，並執行：

byId("heading").textContent = `${vehicle.heading.toFixed(0)}°`;

讀成白話就是：「找到 id 是 heading 的元素，把裡面的文字換成車輛朝向」。textContent 改的是文字，不會重新建立整個 HTML 頁面。

追查小技巧：從畫面文字找程式時，先記下 HTML 的 id，再搜尋 getElementById 或 byId("那個id")。

輪到你追一條欄位

車輛經度在 HTML 裡的 id 是 longitude。你能在 src/monitor.js 找到哪行把經度寫回畫面嗎？請回覆那行程式，或說出它用哪個屬性更新文字。

不必背語法；照著本課的線索搜尋 byId("longitude") 即可。
