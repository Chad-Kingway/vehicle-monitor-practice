Angular 如何切換兩種畫面？

練習看 Angular 範本如何選擇要建立哪個畫面元件。

@if 讓 Angular 按條件顯示內容

Angular 範本中的 @if 和 @else 是畫面控制語法。條件成立時顯示第一個區塊，否則顯示另一個區塊。它不是一般 HTML 標籤，而是 Angular 讀取範本時會處理的指令。

WorkspaceComponent 用它選擇側欄內容：

@if (client.state().mode === 'monitor') {
  <app-monitor />
} @else {
  <app-passenger />
}

app-monitor 對應監控畫面元件，app-passenger 對應乘客畫面元件。Angular 看目前條件，只建立並顯示其中一個區塊。這就是 Angular 在這裡做的事：依資料選擇頁面結構、建立對應的元件畫面。

地圖為什麼不跟著切掉？

同一個範本裡，地圖容器寫在這段 @if 之外：

<main>
  <aside>
    @if (...) { <app-monitor /> }
    @else { <app-passenger /> }
  </aside>

  <section class="map-region">
    <div id="map"></div>
  </section>
</main>

切換分支時，側欄會換成另一個元件；地圖區塊是旁邊獨立的內容，沒有被放進任一分支，因此仍留在頁面。這個結構讓工作區內切換畫面時可以繼續使用同一個地圖。

Angular 範本讀法：@if 選分支；分支裡的元件負責那塊畫面；放在分支外的內容不受這次選擇影響。
