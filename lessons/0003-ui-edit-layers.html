Vehicle Monitor · Lesson 03

UI 修改從哪裡開始？

先分清結構、外觀、互動，再決定要讀哪個檔案。

把網頁想成三層

  • HTML：有哪些東西。例如標題、車輛資料欄、按鈕和地圖區域。
  • CSS：看起來如何。例如顏色、圓角、大小、間距和排列。
  • JavaScript：怎麼動、資料怎麼變。例如按鈕點擊後送出 HTTP 請求，或把 Server 回傳的經度寫到畫面。

這不是三個互不相干的世界：JavaScript 可以建立 HTML 元素，CSS 再依 class 為它們設計外觀。

用車輛資料卡當例子

index.html 宣告資料卡：

<section class="vehicle-card"> ... </section>

src/style.css 有 `.vehicle-card` 規則，設定邊框、圓角、內距與背景色。CSS 用句點選取 class；若要修改這張卡片的外觀，通常從這裡開始。

.vehicle-card {
  border: 1px solid #304055;
  border-radius: 12px;
  padding: 18px 16px 8px;
  background: #18283c;
}

反過來，若要加一個「定位」按鈕，要讀 src/monitor.js：程式建立按鈕、放進車輛卡片，也替按鈕掛上點擊事件。

回到你的問題：對上 id 之後，更新既有文字通常很直接；但版面外觀要看 CSS，新增或改變操作則要看 JavaScript 的建立流程與事件。

判斷從哪裡開始

你想讓車輛資料卡的背景變亮，但文字和操作都不改。你會先打開哪個檔案？在檔案裡搜尋哪個選擇器？

回覆檔名和選擇器即可。提示：選擇器會從 HTML 的 class="..." 找線索。
