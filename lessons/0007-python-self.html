Vehicle Monitor · Lesson 07

self 指的是哪個東西？

讀懂 self.vehicles，就能看出資料放在哪個物件裡。

Simulation 物件保存自己的資料

server/simulation.py 裡有一個 Simulation 類別。建立它時，初始化函式會把資料放在這個物件上：

class Simulation:
    def __init__(self, settings, planner):
        self.settings = settings
        self.planner = planner
        self.vehicles = {...}
        self.requests = {}
        self.tasks = {}

可以先把「物件」想成一個裝著相關資料和功能的東西。這個 Simulation 物件的欄位包含 settings、vehicles、requests 和 tasks。

self 是目前這個物件

self 是 Python 方法常用的第一個參數名稱，指正在執行方法的那個物件。它不是固定代表 app，也不是固定代表單一車輛。

因此 self.vehicles 就是「目前這個 Simulation 物件的 vehicles 欄位」。在 snapshot(self) 裡，self 指向先前放進 app.state.simulation 的那個模擬器。

串起來讀：呼叫 app.state.simulation.snapshot() 時，Python 會讓 self 指向 app.state.simulation；於是方法裡的 self.vehicles 讀到這個模擬器保存的車輛資料。
