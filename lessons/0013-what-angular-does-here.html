Vehicle Monitor · Lesson 13

Angular 在這個專案做什麼？

看懂它如何把 TypeScript、HTML 範本、資料服務與地圖接成一個前端。

Angular 是前端框架，不是另一種語言

這個專案用 TypeScript 寫前端邏輯，用 HTML 範本描述畫面。Angular 把兩者組成可更新的網頁元件，也提供依賴注入、Signals 與 HTTP 整合等工具。Angular CLI 負責開發伺服器與正式建置；瀏覽器最後執行的是建置後的 JavaScript。

從 HTML 找到 Angular 程式

根目錄 index.html 放置 <app-root>。src/main.ts 呼叫 bootstrapApplication(WorkspaceComponent, ...)，告訴 Angular 從哪個元件開始啟動，並提供 HttpClient。

index.html 的 <app-root>
        ↓ Angular 啟動
WorkspaceComponent（整個工作區與地圖）
        ├── MonitorComponent（監控畫面）
        └── PassengerComponent（乘客畫面）
        ↓ 共用
SimulationService → ApiService → FastAPI

上面是責任關係，不代表每次畫面操作都會重建整棵樹。監控或乘客內容由工作區選擇；地圖容器留在工作區層級。

元件把畫面和互動放在一起

MonitorComponent 是一個元件：裝飾器的 selector 給它名稱，template 描述清單與按鈕，TypeScript class 提供資料和操作。範本中的 {{ online() }} 顯示計算值；(click) 把按鈕點擊接到操作。

@Component({
  selector: 'app-monitor',
  template: `<button (click)="client.actions.locate()">定位</button>`
})
export class MonitorComponent {
  readonly client = inject(SimulationService);
}

範本是 Angular 讀的 HTML 樣板，不是瀏覽器直接執行的字串。Angular 會依範本和目前狀態更新實際畫面。

服務負責跨元件共用的資料流程

SimulationService 持有車隊、請求、連線狀態及地圖生命週期，並用 Signal 提供可追蹤的狀態。元件透過 inject(SimulationService) 取得服務；像 client.state() 的讀取會讓範本隨狀態更新。

ApiService 使用 Angular HttpClient 發 HTTP 請求給 FastAPI。Server、Python 車輛 Client 與 HTTP 資料契約沒有因為前端改用 Angular 而改變。地圖 SDK 仍由 vehicle-map.js 封裝，再由 Angular 工作區呼叫。

先記住這條線：元件負責呈現和接收操作；服務負責共享狀態與資料工作；Angular 把狀態變化反映到範本。

小練習

使用者按下「定位」時，按鈕寫著 client.actions.locate()。它是在改 HTML 範本、呼叫 FastAPI，還是把操作交給共用的前端服務？請用自己的話回答，並指出這條流程中哪個檔案啟動 Angular。
