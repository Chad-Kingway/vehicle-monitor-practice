Vehicle Monitor · Lesson 19

Angular 如何把車輛清單畫出來？

用一段 @for 範本，追蹤資料如何變成多個按鈕。

@for 讓 Angular 重複建立畫面

MonitorComponent 用這段範本顯示車隊：

@for (vehicle of fleet(); track vehicle.id) {
  <button (click)="client.actions.selectVehicle(vehicle.id)">
    {{ vehicle.id }}
  </button>
}

用白話讀：Angular 取得 fleet() 的車輛清單；清單裡每有一台車，就建立一個按鈕。每個按鈕內的 vehicle.id 會顯示當下那台車的 ID。三台車就會有三個按鈕。

track vehicle.id 是每列畫面的識別方式

監控頁會定期收到新資料，車輛清單也可能改變。track vehicle.id 告訴 Angular：「用車輛 ID 辨認這一列代表哪台車。」例如清單順序改變，Angular 可以依 ID 對應前後的車輛列，而不只看它排第幾個。若某個 ID 不在新清單中，那台車的按鈕也不再顯示。

Angular 在這裡負責：依清單項目重複範本，並用 track 維持資料項目與畫面列的對應。

練習：推演清單更新

第一次收到的清單是 [vehicle-01, vehicle-02, vehicle-03]；下一次收到 [vehicle-03, vehicle-01]。請回答：

  1. 更新後畫面依序有哪些車輛按鈕？
  2. 哪個按鈕不再顯示？
  3. track vehicle.id 用什麼資料判斷兩次清單中的車輛是否同一台？
