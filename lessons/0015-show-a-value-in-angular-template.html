把一個數字放到 Angular 畫面

先看懂一小段畫面，不需要先學 Signal 或 Service。

畫面上的內容可以來自程式資料

一般 HTML 可以直接寫死文字，例如 <p>在線 2</p>。如果數字會變，就不想每次手動改 HTML。Angular 提供一個寫法：在雙大括號裡放要顯示的資料或計算結果。

<p>在線 {{ online() }}</p>

把它想成「在線」後面留了一個位置給程式填。如果 online() 算出 2，畫面就會顯示「在線 2」。Angular 官方把這種雙大括號顯示文字的方式稱為 text interpolation（文字插值）。

在車輛監控裡找到它

MonitorComponent 的範本有這一行：

<span>在線 {{ online() }}</span>

這裡先只把 online() 當作一個會給出數字的程式；它怎麼算，我們之後再拆。這一課要記得的是：雙大括號裡的結果會出現在網頁文字中。

先讀出這行：「在線」是固定文字；{{ online() }} 是由程式提供的部分。
