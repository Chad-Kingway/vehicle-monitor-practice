Vehicle Monitor · Lesson 01

網頁從哪裡開始？

今天只追一條線：瀏覽器從 HTML 找到第一支 JavaScript。

先看入口，不用一次讀完所有程式

你打開 http://127.0.0.1:5173/ 時，Vite 開發伺服器會把專案根目錄的 index.html 提供給瀏覽器。Vite 官方也把這個 HTML 稱為應用程式的入口。

在這個專案的 index.html 最後可以看到：

<script type="module" src="/src/main.js"></script>

這行告訴瀏覽器去載入 /src/main.js，並把它當成 JavaScript module 執行。Module 可以再用 import 把程式拆到其他檔案。

入口程式做了什麼？

打開 src/main.js，你會看到它先載入樣式與兩個功能：

import "./style.css";
import { mountMonitor } from "./monitor.js";
import { mountPassenger } from "./passenger.js";

接著它檢查網址是否帶有 ?passenger=...。有的話，啟動乘客頁；沒有的話，呼叫 mountMonitor() 啟動監控頁。

抓住這個心智模型：HTML 指向入口；入口再匯入功能模組並決定先啟動哪個畫面。看到 import 時，就沿著路徑去找下一個檔案。

30 秒回想練習

先不要往下找答案，試著自己回答：
① 哪個 HTML 標籤載入 src/main.js？
② 網址沒有 passenger 參數時，入口呼叫哪個函式？
